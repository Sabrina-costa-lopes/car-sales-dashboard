
# Car Sales Dashboard

## Sobre o projeto

Aplicativo web desenvolvido com Python, Pandas, Plotly e Streamlit para explorar dados de anúncios de venda de veículos.

## Funcionalidades

- Visualização da distribuição dos preços dos veículos por meio de um histograma.
- Análise da relação entre o ano do modelo e o preço por meio de um gráfico de dispersão.
- Exploração interativa de um conjunto com 51.525 anúncios.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit
- Jupyter Notebook

## Executar localmente

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute o aplicativo:

```bash
python -m streamlit run app.py
```
